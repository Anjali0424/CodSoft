# CodSoft Python Programming Internship

This repository contains the tasks completed during the **CodSoft Python Programming Internship**.  
Each task demonstrates the use of Python programming concepts, GUI development, and web development using Flask.


 Task 1: To-Do List Application
- Developed using **Flask**, **HTML**, and **CSS**
- Allows users to:
  - Add new tasks
  - Update existing tasks
  - Mark tasks as completed
  - Delete tasks
- Clean and user-friendly interface
- No JavaScript used

 Task 2: Calculator Application
- Developed using **Python Tkinter**
- Supports multiple operations:
  - Addition, Subtraction, Multiplication, Division
  - Modulus, Power, Floor Division
  - Minimum, Maximum, Average
  - Absolute Difference and Clear option
- Professional calculator-style UI

 Task 3: Password Generator
- Developed using **Python Tkinter**
- Generates strong and random passwords
- User can specify password length
- Uses letters, numbers, and special characters
- Simple and professional interface
